Update domain & DNS

Points www.your domain at this Pi's tunnel and updates the tunnel's public hostname. Needs a Cloudflare API token with Zone:Read, DNS:Edit and Cloudflare Tunnel:Edit. It is used once and never stored. Other hostnames on the tunnel are kept.

Replace tunnel token

Use this to move the Pi to a different tunnel. The new token is checked, applied, and the tunnel must connect within about 40 seconds; otherwise the previous token is restored automatically. You can paste the token or the whole cloudflared service install … command.

Saved domain (display only)

Only changes the name shown on the dashboard. It does not touch Cloudflare DNS.

How to connect your domain

  1. Add your domain to Cloudflare and point its nameservers there.
  2. Go to Zero Trust → Networks → Tunnels → click your tunnel.
  3. Open the Public Hostnames tab → Add a public hostname.
  4. Set Domain to your domain, Service to HTTP, URL to localhost:80.
  5. Save — Cloudflare provisions SSL automatically.
